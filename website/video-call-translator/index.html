Questions

Is there an app that translates video calls live?

Yes. Let Talk translates one-on-one video calls on iPhone with live subtitles and spoken translation in each person's language.

Does Let Talk work with Zoom, FaceTime or WhatsApp calls?

No. Let Talk translates calls made inside the Let Talk app. Both people use Let Talk to call each other.

Does the other person need Let Talk?

Yes. Translated calls and messages work between two Let Talk accounts, so the person you're talking to installs Let Talk too. You can add each other by phone number or by scanning a QR code.

How much does Let Talk cost?

Let Talk is a one-time purchase on the App Store. There is no subscription and no per-minute charge for calls or translation.

Is Let Talk available on Android?

Let Talk is available for iPhone today.
