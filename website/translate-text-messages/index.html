Questions

Is there a messaging app that translates automatically?

Yes. Let Talk translates every message into the reader's language as it arrives, and the original text is one tap away.

Can I see the original message?

Yes. Tap a translated message to see the original text.

Does the other person need Let Talk?

Yes. Translated calls and messages work between two Let Talk accounts, so the person you're talking to installs Let Talk too. You can add each other by phone number or by scanning a QR code.
